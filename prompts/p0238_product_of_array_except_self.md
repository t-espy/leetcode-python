## Contract

`product_except_self(nums: list[int]) -> list[int]`

Return a list `out` the same length as `nums` where `out[i]` is the
product of every element except `nums[i]`. Do not use division. `nums`
has length at least two. Zeros are allowed. Run in linear time.
